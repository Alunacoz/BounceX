# BounceX

A music and video visualization tool for creating rhythm-synced animations and path files compatible with [custom OSSM firmware](https://github.com/clbhundley/OSSM-Sauce).

## Download

Grab the latest release for your platform from [Releases](../../releases):

- **Windows** (x64)
- **Linux** (x64)
- **macOS** (arm64)

## Supported Formats

**Audio:** MP3, WAV, OGG

**Video (experimental):** MP4, MKV, WebM, AVI, MOV, WMV, FLV

## Getting Started

1. Download and extract the release for your platform
2. Run the BounceX executable
3. Load an audio or video file
4. Create beat markers synced to your media
5. Render your path as an image sequence, or use the path file (.bx or .funscript) with an interactive device!
